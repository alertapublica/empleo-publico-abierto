# Política de seguridad

Si encuentras una vulnerabilidad (en el código, en los workers de Cloudflare o en el bot de Telegram), **no abras una *issue* pública**. Usa el aviso privado de GitHub: pestaña [Security → Report a vulnerability](https://github.com/alertapublica/empleo-publico-abierto/security/advisories/new).

Incluye qué has encontrado, cómo reproducirlo y qué impacto crees que tiene. Responderemos lo antes posible.

Se consideran de interés, por ejemplo, el acceso a las suscripciones de avisos, la fuga de secretos o cualquier forma de que el proyecto cargue indebidamente los servidores oficiales. Los errores en los datos de una oferta no son de seguridad: abre una *issue* normal.
